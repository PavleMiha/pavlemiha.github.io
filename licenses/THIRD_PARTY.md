# Third-party components

Game code: MIT. The supplied design and reference image remain the user's material.

- Macroquad (MIT / Apache-2.0): rendering and cross-platform window/input. The browser loader is copied from the exact locked crate by the build script. https://github.com/not-fl3/macroquad
- Miniquad (MIT / Apache-2.0): Macroquad's platform backend. https://github.com/not-fl3/miniquad
- mlua (MIT): build-time Lua host. https://github.com/mlua-rs/mlua
- Lua (MIT): embedded by mlua's vendored feature. https://www.lua.org/license.html
- Serde / serde_json (MIT / Apache-2.0): content and save serialization. https://github.com/serde-rs/serde
- Playwright (Apache-2.0): development-only browser testing. https://github.com/microsoft/playwright

Transitive dependency versions are recorded in Cargo.lock and package-lock.json. All graphics, bitmap lettering and sound waveforms are generated by this project; no reference-game assets or external fonts are used.

Distributions include a `licenses` folder containing the notices packaged with the locked Cargo dependencies, including the build-time dependencies for completeness. The browser loader has one compatibility declaration prepended for Macroquad 0.4.16's bundled network plugin; the remainder is unmodified.
